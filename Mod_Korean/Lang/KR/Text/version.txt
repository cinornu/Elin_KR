* 브러싱과 테이밍 시에 난이도가 낮을 수록 대상이 공포 상태가 되기 쉬웠던 것을 수정.
* 문 게이트의 맵 정보 취득 시의 이스케이프 처리, 또 서버 측 이스케이프 처리를 수정.
* 서큐버스가 기분 좋은 일을 해서 잠재능력 경험치를 얻을 때, 취득한 경험치가 0이면 잠재치가 하락했다고 표시되고 있던 것을 수정.
* 손이 없는 상태에서 손이 생겼을 때, 한손으로 든 무기가 PCC 위에서 양쪽 손에 표시되는 것을 수정.
* 하운드 등의 속성에 따라 색깔이 변하는 NPC로 변신했을 때, 속성 색이 그래픽에 반영되지 않았던 것을 수정.
* 스킨이 설정되어 있는 장비를 재구축했을 때, 스킨이 디폴트 스킨으로 돌아가는 것을 수정.
* 네후 마을에 배치된 빨간 책「여우족에 대해」에 NPC 소유 플래그가 여전히 붙어 있던 것을 수정.
* 노래 마법의 툴팁에 표기되는 내성 보너스 수치가 실제로 얻는 보너스 수치와 달랐던 것을 수정.
* 유전자 슬롯이 원래 0인 캐릭터에게 유전자를 삽입할 수 있던 것을 수정.
* 출하 화면 배경 일러스트의 출현 조건이 조금 이상했던 것을 수정.
* 색 선택 윈도우의 컬러 피커로 색을 잘 선택할 수 없던 것을 수정.
* 애니메이션이 붙은 가구 등을 설치할 때, 하이라이트의 애니메이션이 어긋나는 경우가 있던 것을 수정.
* 종족 「반신」으로 플레이 시, 에이스의 제단이 점거 실패하는 경우가 있던 것을 수정.
* 상태 「잠행」이 사격을 해도 해제되지 않던 것을 수정.
* 재화와 관련된 오버플로 수정.
* 그 외 세세한 수정과 조정.
